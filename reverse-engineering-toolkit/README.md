## 使用方法

1. **直接注入**：把对应 .md 的正文（--- 分隔线之后）整段粘贴到模型系统提示词/人格，或作为会话开头的技能指令。
2. **dsh 技能**：复制到 `~/.dsh/skills/<名字>/SKILL.md`，重启 dsh 即可用 `智汇AI` 工作流路由到它。
3. **配合核心框架**：先用「智汇AI深度分析工作流」激活，再用本包技能处理具体样本。

## 为什么不是 391？

ID 391（通用逆向工程师）内容最"通用"，但自带 `Never Assist With: Bypassing software licensing illegitimately` 限制条款，破解场景下模型会自己踩刹车；940/658/283/443 是纯技术 playbook，无此类自限条款，链路更完整。
